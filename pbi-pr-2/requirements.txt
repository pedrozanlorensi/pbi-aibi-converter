# Pinned dependencies. Floor-only specifiers (`>=`) are NOT enough for a
# Databricks App: the runtime resolves the latest matching version on
# every deploy, so a breaking minor upstream release would silently
# brick the app overnight. Use `~=` for "compatible release" pinning
# (PEP 440) — this allows safe patch upgrades but blocks minor jumps.
#
# Streamlit is intentionally pinned to a single minor (1.39) because
# `st.context.headers` and `st.dialog` semantics have shifted across
# minors in the past. Bump deliberately, never automatically.
#
# `streamlit` is provided by the Databricks Apps runtime — listed here
# for local-dev parity but the deploy uses the runtime version.
